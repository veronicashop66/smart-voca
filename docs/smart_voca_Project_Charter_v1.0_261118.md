## 2. 배경 및 목적

- 수능 영어 빈출 단어를 예문과 함께 익히고, 틀린 단어를 반복해서 외우기 위한 개인용 영단어 연습장을 만든다.
- 종이 단어장이나 단순 암기 앱 대신, 틀린 단어가 일정 간격으로 다시 나오도록 해서 복습을 자동화한다.

## 3. 목표

| 번호 | 목표 | 측정 방법 |
| :--- | :--- | :--- |
| G-1 | 수능 빈출 단어 64개를 뜻 맞추기 퀴즈로 학습할 수 있다. | 64개 단어가 모두 퀴즈에 출제된다. |
| G-2 | 틀린 단어가 정해진 간격 뒤에 다시 출제되고, 맞힐 때까지 반복된다. | 재출제 간격이 8~12문제 범위 안에 있는지 테스트로 확인한다. |
| G-3 | 학습 기록이 브라우저에 저장되어, 새로고침 후에도 이어서 볼 수 있다. | 저장 후 새로고침해도 기록이 남는다. |
| G-4 | GitHub Pages에서 설치 없이 접속해 쓸 수 있다. | 배포 URL에서 퀴즈가 동작한다. |

## 4. 범위

### 4.1 포함 (In Scope)

- 뜻 맞추기 퀴즈 (예문 먼저 표시 → 4지선다)
- 정답 판정: 단어의 여러 뜻 중 하나라도 맞으면 정답. 답을 입력한 뒤 나머지 뜻도 함께 보여준다.
- 틀린 단어 재출제 규칙 (4.3)
- 단어별 예문 (단어당 2개 이상, 재출제 시 이전에 보여주지 않은 예문 사용)
- 단어별 한글 뜻 여러 개 (개수 제한 없음)
- 단어 데이터: 현재 `vocab-quiz/js/words.js`의 수능 빈출 단어 64개를 그대로 사용
- 학습 기록 브라우저 저장 (localStorage)
- GitHub Pages 정적 배포

### 4.2 제외 (Out of Scope)

- 화면에서 단어를 추가·수정·삭제하는 기능 (1차·2차 모두 두지 않음)
- 서버, DB, 회원가입·로그인
- 여러 기기 간 기록 동기화
- 발음(TTS), 음성 입력
- 모바일 전용 최적화, 다국어 UI (한국어만 지원)
- 오프라인 전용 동작(PWA) — 기본 웹 접속만 보장
- 정답률 상세 통계 그래프 (기록 저장 이후 검토)

### 4.3 핵심 규칙: 틀린 단어 재출제

- 단어를 틀리면 **틀린 시점 이후 최소 8문제가 지난 뒤**, 그 뒤 0~4문제 사이의 무작위 간격으로 다시 출제한다. 즉 8~12문제 뒤에 나온다.
- 재출제 대상이 여럿이면 그중 하나를 무작위로 고른다.
- 재출제 때는 이전에 보여주지 않은 예문을 쓴다.
- 맞힐 때까지 계속 재출제한다.

## 7. 제약 조건 및 가정

- 빌드 도구·프레임워크 없이 순수 HTML/CSS/JavaScript로 작성한다.
- 서버가 없으므로 기록은 브라우저(localStorage) 단위로 저장된다. 브라우저 데이터를 지우면 기록도 사라진다.
- 배포는 GitHub Pages 정적 호스팅을 사용한다.
- 단어와 예문은 작성자가 직접 작성한다. 외부 자료를 복사하지 않는다.
- 테스트는 Node.js 내장 `node:test`를 사용한다(Node 18 이상).
