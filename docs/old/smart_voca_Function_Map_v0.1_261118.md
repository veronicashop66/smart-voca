# smart-voca 기능 분해도

**파일 위치**: `docs/smart_voca_Function_Map_v1.0_261118.md` (승인 후 복제)
**작성일**: 2026-11-18
**버전**: v0.1 (검토용 초안)
**설명**: 요구사항 명세서(FR-01~28)의 기능을 원자 단위로 분해하고, 각 기능이 구현될 모듈과 연결하는 문서이다.

---

## 1. 분해 원칙

- 최상위는 요구사항 영역 5개로 나눈다.
- 말단 기능(원자 단위)은 한 함수나 한 화면 요소가 책임질 수 있는 크기로 쓴다.
- 각 말단 기능에는 요구사항 ID(FR)를 붙이고, 구현 모듈을 적는다.

## 2. 기능 트리

```
S1. 단어 데이터 관리 ─────────────────────────── (js/words.js, js/quiz.js)
 ├─ S1.1 단어 데이터 로드               FR-01
 └─ S1.2 단어 데이터 검증               FR-02, FR-03
     ├─ 예문 2개 이상 확인
     ├─ 뜻 중복 없음 확인
     └─ 오답 후보 충분성 확인 (선택지 수 기준)

S2. 세션 출제 관리 ───────────────────────────── (js/quiz.js)
 ├─ S2.1 신규 단어 출제                  FR-04
 ├─ S2.2 재출제 관리
 │   ├─ S2.2.1 틀린 단어 재출제 대기 등록  FR-12
 │   ├─ S2.2.2 재출제 시점 계산 (8 + 0~4)  FR-13
 │   ├─ S2.2.3 재출제 대상 선택 (무작위)    FR-14
 │   ├─ S2.2.4 간격 미충족 시 예외 처리     FR-17
 │   └─ S2.2.5 맞힐 때까지 반복             FR-16
 ├─ S2.3 우선순위 결정 (재출제 → 신규)      FR-04, Q-1
 └─ S2.4 세션 종료 판정                    FR-19

S3. 문제 생성 ───────────────────────────────── (js/quiz.js)
 ├─ S3.1 예문 선택 (이전 예문 제외)          FR-08
 ├─ S3.2 오답 후보 필터 (뜻 겹침 제외)        FR-07
 ├─ S3.3 선택지 구성 (정답 1 + 오답 3, 섞기)  FR-07
 └─ S3.4 문제 번호와 출제 유형 부여           FR-15, FR-18

S4. 답변 처리 ───────────────────────────────── (js/quiz.js, js/app.js)
 ├─ S4.1 정오 판정                        FR-09
 ├─ S4.2 첫 시도 정답 집계                  FR-20
 ├─ S4.3 정답 뜻(여러 뜻) 표시              FR-10
 └─ S4.4 다음 버튼 상태 전환                FR-11

S5. 화면 표시 ───────────────────────────────── (index.html, js/app.js)
 ├─ S5.1 진행 상황 표시                    FR-18
 ├─ S5.2 예문 렌더링 (단어 밑줄)            FR-05, FR-06
 ├─ S5.3 선택지 버튼 렌더링                 FR-05
 ├─ S5.4 결과 화면                        FR-20
 └─ S5.5 다시 시작                        FR-21, FR-26

S6. 학습 기록 저장 (신규) ─────────────────────── (js/storage.js, 신규)
 ├─ S6.1 단어별 누적 정오 기록 저장·조회      FR-22
 ├─ S6.2 진행 세션 상태 저장·복원            FR-23, FR-24
 ├─ S6.3 세션 상태 삭제 (완료 시)            FR-25
 ├─ S6.4 저장 데이터 손상 판정·무시·알림      FR-27
 └─ S6.5 저장 항목 제한 (개인정보 없음)       FR-28
```

## 3. 기능별 모듈 배치

| 모듈 | 파일 | 담당 기능 |
| :--- | :--- | :--- |
| 단어 데이터 | `vocab-quiz/js/words.js` | S1.1 |
| 퀴즈 로직 | `vocab-quiz/js/quiz.js` | S1.2, S2, S3, S4.1~S4.2 |
| 저장소 어댑터 | `vocab-quiz/js/storage.js` (신규) | S6 전체 |
| 화면 제어 | `vocab-quiz/js/app.js` | S4.3~S4.4, S5, S6 호출 |
| 화면 마크업·스타일 | `vocab-quiz/index.html` | S5 (레이아웃) |

## 4. 구현 영향

- `quiz.js`에 세션 상태를 내보내고 복원하는 함수가 필요합니다. (S6.2와 연결) 내부는 단어 번호로 관리하고, 저장할 때는 단어 문자열로 바꿉니다.
- `words.js`는 변경하지 않습니다.
- `app.js`는 세션 시작 시 복원을 시도하고, 답변 후 저장하고, 완료 시 삭제합니다.
- S5.2(밑줄)은 `index.html`의 CSS에서 `strong` 스타일을 밑줄로 바꾸면 됩니다.

## 5. 검토 포인트

1. S2.3의 우선순위(재출제 먼저)가 명세서 Q-1과 맞는지
2. S6.4의 손상 판정 기준은 데이터 설계서에서 정한다. 기능 분해에서는 "무시하고 알림"까지만 정한다.
3. 기능 수준이 1인 개발에 맞게 과하지 않은지
