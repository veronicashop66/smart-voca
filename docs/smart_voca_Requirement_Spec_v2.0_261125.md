## 0. 범위 변경 요약

| 항목 | 기존 v1.0 (`docs/`) | 소프트웨어 요건 v1.1 (본 초안) |
| :--- | :--- | :--- |
| 실행 형태 | 정적 HTML/JS, 브라우저에서 파일 열기 | 웹 앱, 학교 서버 Docker 배포 |
| 데이터 | localStorage / 세션 | SQLite DB (단어, 암기·시험 이력, 사용자, 설정) |
| 핵심 기능 | 객관식 퀴즈, 오답 재출제 | 단어 등록·CSV 가져오기, 암기 진도, 시험, 학습 통계 |
| 계정 | 없음 | 도전: 로그인, 계정별 이력, 다른 계정 이력 보기 |

> 결정: 기존 퀴즈(`vocab-quiz/`)는 새 웹 앱으로 대체합니다 (ADR-006).

## 1. 기능 요구사항 (VOCA-FR)

수준: **기본** = 필수, **도전** = 가산점. 확인: 시연 / 코드 / DB.

### 1.1 단어 등록 (기본)

| ID | 요구사항 | 확인 |
| :--- | :--- | :--- |
| VOCA-FR-001 | 영단어와 뜻을 직접 입력해 등록 | 시연 |
| VOCA-FR-002 | 단어 목록 조회, 수정, 삭제 | 시연 |
| VOCA-FR-003 | 제공 CSV(`영단어,뜻`, 2,000개) 일괄 등록. 중복 처리 방식은 직접 정해 문서화 | 시연·코드 |
| VOCA-FR-004 | 영단어 또는 뜻으로 검색 | 시연 |

### 1.2 암기 (기본)

| ID | 요구사항 | 확인 |
| :--- | :--- | :--- |
| VOCA-FR-011 | 하루 학습량(단어 수)에 따라 1일차, 2일차 … 진도 생성 | 시연·코드 |
| VOCA-FR-012 | 그날 단어를 한 장씩 보며 암기 (영단어 → 뜻 보기) | 시연 |
| VOCA-FR-013 | 전날 암기한 단어 일부와 자주 틀린 단어를 그날 암기에 섞음 | 코드·DB |
| VOCA-FR-014 | 암기 이력(사용자, 시각, 단어, 일차)을 DB에 저장 | DB |

### 1.3 시험 (기본)

| ID | 요구사항 | 확인 |
| :--- | :--- | :--- |
| VOCA-FR-021 | 문제 수를 정하면 그 수만큼 출제 | 시연 |
| VOCA-FR-022 | 무작위 출제하되, 미출제·오래된·자주 틀린 단어가 더 자주 나오게 함 | 코드 |
| VOCA-FR-023 | 출제 방향 선택: 영→한, 한→영, 섞기 | 시연 |
| VOCA-FR-024 | 출제 형식 2가지 이상 지원 (단답형, 4지선다, OX 중 택 2 이상) | 시연 |
| VOCA-FR-025 | 채점 결과 표시 (점수, 틀린 문항과 정답) | 시연 |
| VOCA-FR-026 | 문항 단위 시험 이력 저장 (단어, 형식, 방향, 정오, 시각) | DB |

### 1.4 학습 진척 통계 (기본)

| ID | 요구사항 | 확인 |
| :--- | :--- | :--- |
| VOCA-FR-031 | 진도 현황: 현재 일차, 암기한 단어 수 / 전체 | 시연 |
| VOCA-FR-032 | 시험 성적 추이: 회차별·날짜별 정답률 | 시연 |
| VOCA-FR-033 | 자주 틀리는 단어 상위 N개 | 시연 |
| VOCA-FR-034 | 통계는 DB 이력으로 계산 (화면 값을 직접 기록하지 않음) | 코드 |

### 1.5 로그인 (도전)

| ID | 요구사항 | 확인 |
| :--- | :--- | :--- |
| VOCA-FR-041 | 회원 가입, 로그인, 로그아웃 | 시연 |
| VOCA-FR-042 | 비밀번호 해시 저장 (평문 금지) | 코드·DB |
| VOCA-FR-043 | 암기·시험 이력과 통계를 계정별로 분리 | 시연·DB |

### 1.6 다른 계정 이력 보기 (도전, FR-041 필요)

| ID | 요구사항 | 확인 |
| :--- | :--- | :--- |
| VOCA-FR-051 | 다른 사용자의 학습 통계 조회 (목록 또는 순위표) | 시연 |
| VOCA-FR-052 | 공개 여부는 본인이 설정. 비공개 사용자 이력은 노출하지 않음 | 시연 |
| VOCA-FR-053 | 타인 이력은 조회만 가능 (수정·삭제 불가) | 시연·코드 |

### 1.7 설정 (도전)

| ID | 요구사항 | 확인 |
| :--- | :--- | :--- |
| VOCA-FR-061 | 설정 화면에서 하루 학습량, 복습 비율, 시험 기본값(문제 수·방향·형식) 변경 | 시연 |
| VOCA-FR-062 | 설정을 DB에 저장하고 재접속 후에도 유지 (계정이 있으면 계정별) | 시연·DB |

> 참고: 하루 학습량(VOCA-FR-011)은 기본 수준에도 필요합니다. 기본 수준에서는 고정값이나 간단한 입력으로 충분하고, 설정 화면에서 관리하는 것은 도전입니다.

## 3. 제출 요건 (VOCA-SUB)

### 3.1 리포와 제출

| :--- | :--- |

| ID | 요건 |
| :--- | :--- |

### 3.4 서버 배포

| ID | 요건 |
| :--- | :--- |
| VOCA-SUB-031 | 리포 루트 `Dockerfile`, `docker build .` 한 번으로 이미지 생성. Dockerfile 규칙 R-01~R-10 준수 |
| VOCA-SUB-032 | 컨테이너는 `0.0.0.0:8080`에서 응답 |
| VOCA-SUB-033 | 앱은 `/` 기준으로 작성. 주소는 `/`로 시작하거나 상대 경로 사용. 호스트 미사용, HTML 속성은 따옴표 사용 |
| VOCA-SUB-034 | UID 10001, 권한 없이 실행해도 동작 |
| VOCA-SUB-035 | SQLite(`DB_PATH`) 사용. 쓰기는 `/data`·`/tmp`에만 |
| VOCA-SUB-036 | 실행 중 인터넷 불필요. 비밀값은 환경변수 |
| VOCA-SUB-037 | `.github/workflows/docker-check.yml`을 고치지 않고 포함. 제출 커밋에서 초록 통과 |

> 확인 필요: 「Dockerfile 구성」 상세 규칙(R-01~R-10)과 앱 주소(`/2026/voca-<학번>/`)는 요건 파일에 요약만 있습니다. 원문을 받아 대조해야 합니다.
