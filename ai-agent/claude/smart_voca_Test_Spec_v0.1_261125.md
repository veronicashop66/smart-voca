## 시나리오

### FR-001~004 단어 등록

- **시나리오 1: 직접 등록**
  - Given 등록된 단어가 없다
  - When `abandon`, 뜻 `버리다`를 등록한다
  - Then 목록에 나타나고, 같은 영단어(대소문자 무시)를 다시 등록하면 409를 받는다 (자동: `api.test.js` 단어 등록·수정·삭제)
- **시나리오 2: 수정과 삭제**
  - Given 단어 `abandon`이 있다
  - When 뜻을 `포기하다`로 수정하고, 그 뒤 삭제한다
  - Then 수정 값이 저장되고, 삭제한 단어를 다시 삭제하면 404다 (자동)
- **시나리오 3: CSV 가져오기 (중복 처리)**
  - Given 빈 DB다
  - When `Peck,쪼다`와 `peck,찌르다`가 들어 있는 CSV를 가져온다
  - Then 한 단어로 저장되고 뜻은 `쪼다; 찌르다`다. 같은 파일을 다시 가져오면 모두 건너뛴다 (자동: `api.test.js`, `logic.test.js`)
- **시나리오 4: 실제 샘플 CSV (수동)**
  - Given `ai-agent/uploads/단어사전_샘플.csv`(2,000행)를 준비한다
  - When 단어 탭에서 파일을 고른다
  - Then 전체 2,000행, 추가 1,999개, 뜻 합침 1개, 오류 0개가 표시된다 (2026-11-25 API로 확인 완료, 화면 확인은 미실시)
- **시나리오 5: 검색**
  - Given 단어가 등록되어 있다
  - When 검색창에 뜻의 일부를 입력하고 검색한다
  - Then 영단어 또는 뜻에 포함된 단어만 나온다 (수동)

### FR-011~014 암기

- **시나리오 6: 일차 진도**
  - Given 단어 2,000개, 하루 학습량 20이다
  - When 암기 탭을 열면
  - Then 1일차 새 단어 20개가 보이고, 전체는 100일이다 (자동 테스트 없음, 2026-11-25 실제 CSV로 API 확인)
- **시나리오 7: 완료 기록과 다음 날**
  - Given 1일차 단어 목록이 보인다
  - When 날짜가 맞지 않게 완료를 보내면 400, 맞게 보내면 200이다
  - Then 다음 조회는 2일차이고, 전날 단어가 복습으로 섞인다 (자동: `api.test.js` 암기)
- **시나리오 8: 뜻 가리기**
  - Given 암기 카드가 보인다
  - When "뜻 보기"를 누른다
  - Then 뜻이 나타나고 버튼이 "뜻 가리기"로 바뀐다 (수동)

### FR-021~026 시험

- **시나리오 9: 출제 수와 보기**
  - Given 단어가 10개 이상 있다
  - When 4지선다, 4문제로 시험을 시작한다
  - Then 4문제가 나오고 각 문제는 보기 4개를 가진다. 보기 안에 정답 뜻과 겹치는 뜻이 없다 (자동: `logic.test.js`, `api.test.js`)
- **시나리오 10: 정답을 응답에서 숨김**
  - Given 시험이 시작되었다
  - When 출제 응답을 받는다
  - Then 응답에 정답 필드가 없다 (자동)
- **시나리오 11: 채점과 재제출 방지**
  - Given 시험을 제출했다
  - When 같은 시험을 다시 제출하면
  - Then 409를 받는다 (자동)
- **시나리오 12: 단답형 채점**
  - Given 단어 `level`, 뜻 `수준; 정도`
  - When 영→한에서 `정도`, 한→영에서 `LEVEL`을 입력한다
  - Then 둘 다 정답이다. 빈 답은 오답이다 (자동: `logic.test.js`)
- **시나리오 13: 설정 범위 검증**
  - Given 로그인 상태다
  - When 문제 수 500, 출제 형식 `ox`를 보내면
  - Then 400을 받는다 (자동)

### FR-031~034 통계

- **시나리오 14: 통계는 이력으로 계산**
  - Given 시험을 1회 제출했다
  - When 통계 탭을 열면
  - Then 푼 시험 수 1, 정답률이 `정답 수 / 문항 수`로 나오고 틀린 단어가 목록에 나온다 (자동: `api.test.js` 시험)

### FR-041~043 계정

- **시나리오 15: 가입과 로그인**
  - Given 게스트 상태다
  - When 가입하면 201, 같은 아이디로 가입하면 409다
  - Then 가입 후 아이디가 표시된다 (자동)
- **시나리오 16: 비밀번호 해시**
  - Given 가입했다
  - When DB의 비밀번호 열을 읽으면
  - Then `scrypt$`로 시작하고 평문이 없다 (자동)
- **시나리오 17: 틀린 비밀번호**
  - Given 가입한 계정이 있다
  - When 틀린 비밀번호로 로그인하면
  - Then 401을 받는다 (자동)
- **시나리오 18: 계정별 분리**
  - Given 계정 A가 암기를 완료했다
  - When 다른 계정 B가 통계를 보면
  - Then 암기 단어 수가 0이다 (자동)

### FR-051~053 다른 사용자 이력

- **시나리오 19: 비공개와 공개**
  - Given 사용자 A의 공개 설정이 꺼져 있다
  - When 사용자 B가 A의 통계를 보면 404다. A가 공개로 바꾸면 B는 통계를 본다 (자동)
- **시나리오 20: 읽기 전용**
  - Given 사용자 A가 공개되어 있다
  - When 사용자 B가 A의 통계에 쓰기 요청(PUT)을 보내면 405다 (자동)

### FR-061~062 설정

- **시나리오 21: 설정 저장 유지**
  - Given 설정에서 하루 학습량을 5로 바꾸고 저장했다
  - When 다시 접속하면
  - Then 설정 화면에 5가 나온다 (저장 API는 `api.test.js` 암기 시나리오에서 사용, 재접속 화면 확인은 수동)

### VOCA-NFR-004 비밀값

- **시나리오 22: 기본 비밀값 없음**
  - Given 코드를 읽는다
  - When 비밀값 관련 키를 찾으면
  - Then 코드에 기본 비밀값이 없다. 세션 토큰은 요청마다 무작위로 만든다 (코드 확인)
