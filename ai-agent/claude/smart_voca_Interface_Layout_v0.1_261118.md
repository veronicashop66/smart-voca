## 1. 화면 구성 (단일 화면)

```
┌──────────────────────────────────────────────┐
│  수능 영단어 뜻 맞추기                          │
│  3번째 문제 · 남은 신규 50개 · 재출제 대기 2개    │  ← 진행 표시 (FR-18)
│                                              │
│  [ 새 단어 ]                                   │  ← 유형 태그 (FR-15)
│  ┌──────────────────────────────────────┐    │
│  │ The crew had to <u>abandon</u> the    │    │  ← 예문, 단어 밑줄 (FR-05, FR-06)
│  │ sinking ship.                        │    │
│  └──────────────────────────────────────┘    │
│  아래 예문의 밑줄 단어 뜻은?                     │  ← 질문 문구
│  ┌──────────────────────────────────────┐    │
│  │ 1. 버리다, 포기하다                      │    │  ← 선택지 버튼 4개 (FR-05)
│  │ 2. 분석하다                             │    │
│  │ 3. 성취하다, 달성하다                    │    │
│  │ 4. 바꾸다, 변경하다                      │    │
│  └──────────────────────────────────────┘    │
│  [정오 피드백 문구]                             │  ← FR-09, FR-10
│  [ 다음 ]  또는  [ 결과 보기 ]                  │  ← FR-11
└──────────────────────────────────────────────┘
```

- 화면 폭은 최대 640px, 모바일에서는 화면 폭에 맞춘다. (NFR-04)
- 색 기준: 정답 초록(`#16a34a` 테두리), 오답 빨강(`#dc2626` 테두리), 강조 파랑(`#2563eb`).

## 2. 요소별 명세

| 요소 | 위치 | 내용 | 요구사항 |
| :--- | :--- | :--- | :--- |
| 제목 | 상단 | "수능 영단어 뜻 맞추기" | — |
| 진행 표시 | 제목 아래 | "N번째 문제 · 남은 신규 X개 · 재출제 대기 Y개" | FR-18 |
| 유형 태그 | 예문 위 | "새 단어" 또는 "다시 풀기" | FR-15 |
| 예문 | 중앙 박스 | 단어에 밑줄. 굴절형도 밑줄 (예: `analyzes`) | FR-05, FR-06 |
| 질문 문구 | 예문 아래 | "아래 예문의 밑줄 단어 뜻은?" | FR-05 |
| 선택지 | 세로 목록 | 버튼 4개, 번호 붙임 | FR-05, FR-07 |
| 피드백 | 선택지 아래 | 정답 또는 오답 문구와 정답 뜻 전체 | FR-09, FR-10 |
| 다음 버튼 | 하단 | 답 후 표시. 마지막 문제는 "결과 보기" | FR-11 |
| 복원 알림 | 상단 띠 | 세션 손상 또는 기록 손상 시 1회 표시 | FR-27 |
| 결과 화면 | 퀴즈 대신 표시 | 요약 문구, "다시 시작" 버튼 | FR-19 ~ FR-21 |

## 3. 피드백 문구 규칙

| 상황 | 문구 | 스타일 |
| :--- | :--- | :--- |
| 정답 | "정답입니다!" | 초록 글씨 |
| 오답 | "오답입니다. "{단어}" = {정답 뜻 전체}" | 빨간 글씨 |

- 정답 뜻 전체는 단어 데이터의 `meaning` 문자열을 그대로 쓴다. 쉼표로 묶인 여러 뜻을 모두 보여준다. (FR-10)
- 정답 선택지 버튼은 답 후에도 초록으로 표시한다. 틀린 선택은 빨강으로 표시한다.
- 답 후에는 선택지 버튼을 모두 비활성화한다. 같은 문제에 두 번 답할 수 없다.

## 4. 상태별 화면

| 상태 | 화면 |
| :--- | :--- |
| 문제 대기 | 예문, 선택지 4개, 피드백 없음, 다음 버튼 숨김 |
| 답변 후 | 선택지 색 표시, 피드백 표시, 다음 버튼 표시 |
| 마지막 문제 답변 후 | 다음 버튼 문구가 "결과 보기" |
| 결과 | 퀴즈 영역 숨김, 요약과 "다시 시작" 표시 |
| 데이터 오류 | 퀴즈 영역 대신 오류 문구 표시 |
| 이어하기 | 저장된 문제를 같은 보기로 표시. 별도 안내 없음. |

## 5. 사용자 흐름

```
페이지 열기
  ├─ 이전 진행 상태 있음 → 같은 문제로 이어서 시작
  └─ 없음 → 새 세션 시작
        │
        ▼
  문제 풀기 (보기 선택) ──▶ 피드백 확인 ──▶ 다음
        ▲                                    │
        └────────── 재출제 포함 반복 ◀───────┘
                                             │
                          신규·재출제 모두 없음
                                             ▼
                                    결과 화면 ──▶ 다시 시작 ──▶ 새 세션
```

## 6. 접근성과 입력

- 선택지는 `<button>`이므로 Tab 키와 Enter 키로 고를 수 있다.
- 번호(1~4)를 버튼 앞에 표시해 번호로 고르는 것을 알 수 있게 한다.
- 키보드 단축키(숫자 키로 선택)는 이번 범위에 넣지 않는다. 필요해지면 별도 요구사항으로 추가한다.
- 색으로만 정오를 구분하지 않는다. 피드백 문구에 "정답입니다!" 또는 "오답입니다."를 함께 쓴다.
